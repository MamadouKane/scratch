🏃 À toute vitesse : la course du chat

Niveau 2, mission 2. Le chat doit traverser la scène de gauche à droite avant la fin du chrono. Attention aux crabes : chaque crabe touché fait perdre une vie !

Mouvement Apparence Événements Contrôle Capteurs Opérateurs Variables

Le but du jeu

Avec les flèches du clavier, amène le chat jusqu'à l'arrivée, à droite. Tu as 3 vies et 60 secondes. Si un crabe te touche, tu perds une vie et tu repars du début.

Joueur : le chat Sprite1 Obstacles : Crab et Crab2 2 variables : Vies, Temps

Avant de coder

Préparer le projet

1

Le chat se place au départ

  1. Clique sur le sprite Sprite1 (le chat).
  2. Pose les blocs dans l'ordre. mettre Vies à 3 est dans Variables : choisis Vies dans son menu.

Ce code va dans le sprite Sprite1 (le chat)

quand @greenFlag est cliqué
mettre [Vies v] à (3)
mettre la taille à (40) % de la taille initiale
fixer le sens de rotation [gauche-droite v]
aller à x: (-200) y: (0)

💡 Au début de chaque partie : le chat a 3 vies, il devient plus petit, et il se place tout à gauche (x = -200). C'est la ligne de départ.

Teste : drapeau vert 🏁. Le chat est petit, à gauche, et « Vies 3 » s'affiche.

2

Le chat avance avec les flèches

  1. Toujours dans le sprite Sprite1, pose la boucle répéter indéfiniment sous le drapeau.
  2. Mets 4 blocs si … alors dedans, l'un sous l'autre.
  3. Dans chaque si, glisse le bloc bleu clair touche … pressée ? (Capteurs) et choisis une flèche différente.

Ce code va dans le sprite Sprite1 (le chat)

quand @greenFlag est cliqué
répéter indéfiniment
si <touche [flèche droite v] pressée ?> alors
s'orienter à (90)
ajouter (4) à x
fin
si <touche [flèche gauche v] pressée ?> alors
s'orienter à (-90)
ajouter (-4) à x
fin
si <touche [flèche haut v] pressée ?> alors
ajouter (4) à y
fin
si <touche [flèche bas v] pressée ?> alors
ajouter (-4) à y
fin
fin

💡 La boucle regarde sans arrêt quelle flèche est appuyée. Quand le jeu se termine (gagné ou perdu), la boucle s'arrête aussi : le chat ne peut plus bouger.
x = gauche ↔ droite, y = bas ↕ haut. Un nombre positif va à droite ou en haut, un nombre négatif (avec -) va à gauche ou en bas.

Teste : drapeau vert 🏁, puis garde une flèche appuyée. Le chat avance tout seul dans les 4 directions.

3

Les crabes montent et descendent

  1. Clique sur le sprite Crab et pose ces 2 scripts.
  2. abscisse x est un bloc rond tout en bas de Mouvement. Glisse-le dans la case x du bloc glisser.
  3. Dans envoyer à tous, crée un Nouveau message appelé touché.

Ces 2 codes vont dans le sprite Crab (le crabe)

quand @greenFlag est cliqué
répéter indéfiniment
glisser en (2) secondes à x: (abscisse x) y: (130)
glisser en (2) secondes à x: (abscisse x) y: (-130)
fin
quand @greenFlag est cliqué
répéter indéfiniment
si <touche le [Sprite1 v] ?> alors
envoyer à tous [touché v]
attendre (1) secondes
fin
fin

💡 Script de gauche : le crabe glisse en haut, puis en bas, sans arrêt. Il met 2 secondes pour chaque trajet. abscisse x veut dire « reste à ta place de gauche à droite ».
Script de droite : si le crabe touche le chat, il envoie le message touché au chat.

Teste : drapeau vert 🏁. Les 2 crabes montent et descendent, chacun à sa place.

4

Touché : on perd une vie

  1. Clique sur le sprite Sprite1 (le chat) et ajoute ce script.
  2. Le bloc = est dans Opérateurs, le bloc rond Vies dans Variables.

Ce code va dans le sprite Sprite1 (le chat)

quand je reçois [touché v]
ajouter (-1) à [Vies v]
aller à x: (-200) y: (0)
si <(Vies) = (0)> alors
dire [Perdu !] pendant (2) secondes
stop [tout v]
fin

💡 Quand un crabe le touche, le chat perd 1 vie et retourne au départ. Comme il est loin du crabe, il ne perd qu'une seule vie à la fois. S'il n'a plus de vie : « Perdu ! » et tout s'arrête : les crabes, le chrono et le chat.

Teste : fonce exprès sur un crabe. Les vies baissent de 1 et le chat repart à gauche. À 0 vie, c'est perdu.

5

Le chrono : 60 secondes

  1. Toujours dans le sprite Sprite1 (le chat), ajoute ce script.
  2. répéter jusqu'à ce que est dans Contrôle.

Ce code va dans le sprite Sprite1 (le chat)

quand @greenFlag est cliqué
mettre [Temps v] à (60)
répéter jusqu'à ce que <(Temps) = (0)>
attendre (1) secondes
ajouter (-1) à [Temps v]
fin
dire [Temps écoulé !] pendant (2) secondes
stop [tout v]

💡 Le temps commence à 60. Chaque seconde, il baisse de 1 : 60, 59, 58… Quand il arrive à 0, c'est fini !

Teste : drapeau vert 🏁 et ne bouge pas. Le temps descend jusqu'à 0, puis le chat dit « Temps écoulé ! ».

6

L'arrivée : gagné !

  1. Toujours dans le sprite Sprite1 (le chat), ajoute ce dernier script.
  2. Le bloc > est dans Opérateurs, abscisse x tout en bas de Mouvement.

Ce code va dans le sprite Sprite1 (le chat)

quand @greenFlag est cliqué
attendre jusqu'à ce que <(abscisse x) > (200)>
dire [Gagné !] pendant (2) secondes
stop [tout v]

💡 abscisse x dit où est le chat de gauche à droite. Quand il dépasse 200, il est tout à droite : il a franchi l'arrivée ! stop tout arrête ensuite tout le jeu.

Teste : traverse toute la scène sans toucher de crabe. Le chat dit « Gagné ! ».
