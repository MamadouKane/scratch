Jeu Pong Scratch

🏓 Jeu Pong : crée ton premier jeu

Suis les étapes dans l'ordre. À chaque étape : recopie les blocs, puis clique sur le drapeau vert pour tester. La couleur d'un bloc te dit dans quelle catégorie le trouver.

Mouvement Apparence Son Événements Contrôle Capteurs Opérateurs Variables

Le but du jeu

La balle rebondit partout. Avec la souris, déplace la raquette pour la renvoyer. Chaque rebond sur la raquette donne 1 point. Si la balle touche la ligne rouge, c'est perdu. À 15 points, tu as gagné !

3 sprites : Ball, Paddle, Line 1 décor : Neon Tunnel 1 variable : Score

Avant de coder

Préparer le projet

1

La balle rebondit partout

clique d'abord sur le sprite Ball
  1. Prends le chapeau jaune dans Événements.
  2. Accroche les blocs bleus de Mouvement en dessous.
  3. Dans Contrôle, prends répéter indéfiniment et mets les 2 blocs bleus à l'intérieur.

Ce code va dans le sprite Ball (la balle)

quand @greenFlag est cliqué
aller à x: (0) y: (100)
s'orienter à (45)
répéter indéfiniment
avancer de (15) pas
rebondir si le bord est atteint
fin

💡 s'orienter à 45 fait partir la balle en diagonale. répéter indéfiniment est une boucle : la balle avance, encore et encore, sans s'arrêter. Quand elle touche un bord, elle rebondit.

Teste : clique sur le drapeau vert 🏁. La balle doit rebondir sur les 4 bords. Clique sur le rond rouge pour arrêter.

2

La raquette suit la souris

clique sur le sprite Paddle
  1. Prends le chapeau jaune, puis le bloc bleu aller à x: 0 y: -120 (écris bien les nombres).
  2. Ajoute la boucle répéter indéfiniment.
  3. Dans Mouvement, prends mettre x à et mets-le dans la boucle.
  4. Dans Capteurs, prends le petit bloc rond souris x et glisse-le dans le rond blanc du bloc bleu.

Ce code va dans le sprite Paddle (la raquette)

quand @greenFlag est cliqué
aller à x: (0) y: (-120)
répéter indéfiniment
mettre x à (souris x)
fin

💡 aller à x: 0 y: -120 place la raquette en bas, au bon endroit, à chaque partie. x, c'est la position gauche ↔ droite. souris x donne la position de ta souris. La raquette se met donc toujours au même endroit que la souris.

Teste : drapeau vert 🏁, puis bouge la souris de gauche à droite sur la scène. La raquette te suit !

3

La balle rebondit sur la raquette

reviens sur le sprite Ball

On ajoute un deuxième script à la balle, à côté du premier. Ne supprime pas le premier !

  1. Dans Contrôle, prends si … alors et mets-le dans une boucle répéter indéfiniment.
  2. Dans Capteurs, prends touche le … ?, glisse-le dans le trou pointu du si, puis choisis Paddle dans le menu.
  3. Dans Opérateurs, prends nombre aléatoire entre … et … et glisse-le dans le rond du bloc tourner. Écris 170 et 190.

Ce code va dans le sprite Ball (la balle)

quand @greenFlag est cliqué
répéter indéfiniment
si <touche le [Paddle v] ?> alors
tourner @turnRight de (nombre aléatoire entre (170) et (190)) degrés
avancer de (15) pas
attendre (0.5) secondes
fin
fin

💡 si … alors est une condition : SI la balle touche la raquette, ALORS elle fait demi-tour. Le nombre aléatoire est choisi au hasard par l'ordinateur : la balle ne repart jamais exactement pareil. attendre 0.5 secondes laisse à la balle le temps de s'éloigner.

Teste : drapeau vert 🏁. Place la raquette sous la balle : elle doit repartir vers le haut.

4

Perdu ! La ligne rouge arrête le jeu

A. Clique sur le sprite Line et pose ce petit script. Il remet la ligne tout en bas à chaque partie.

Ce code va dans le sprite Line (la ligne rouge)

quand @greenFlag est cliqué
aller à x: (0) y: (-170)

B. Clique sur le sprite Ball et ajoute ce troisième script, à côté des deux autres.

Ce code va dans le sprite Ball (la balle)

quand @greenFlag est cliqué
attendre jusqu'à ce que <touche le [Line v] ?>
stop [tout v]

💡 attendre jusqu'à ce que (dans Contrôle) ne fait rien… jusqu'au moment où la balle touche la ligne. Alors stop tout arrête le jeu : c'est le « game over ».

Teste : drapeau vert 🏁, et laisse tomber la balle exprès. Tout doit s'arrêter quand elle touche la ligne rouge.

5

On compte les points

dans le sprite Ball

Ajoute maintenant 2 blocs orange dans les deux scripts de la balle que tu as déjà. À gauche : mettre Score à 0, juste sous le chapeau. À droite : ajouter 1 à Score, en premier dans le si.

Ce code va dans le sprite Ball (la balle)

quand @greenFlag est cliqué
mettre [Score v] à (0)
aller à x: (0) y: (100)
s'orienter à (45)
répéter indéfiniment
avancer de (15) pas
rebondir si le bord est atteint
fin
quand @greenFlag est cliqué
répéter indéfiniment
si <touche le [Paddle v] ?> alors
ajouter (1) à [Score v]
tourner @turnRight de (nombre aléatoire entre (170) et (190)) degrés
avancer de (15) pas
attendre (0.5) secondes
fin
fin

💡 mettre Score à 0 : au début de chaque partie, on repart de zéro. ajouter 1 à Score : à chaque fois que la balle touche la raquette, tu gagnes 1 point.

Teste : drapeau vert 🏁. Le score commence à 0 et monte de 1 à chaque rebond sur la raquette.

6

Gagné ! À 15 points

dans le sprite Ball
  1. Dans Opérateurs, prends le bloc vert pointu … = … et glisse-le dans attendre jusqu'à ce que.
  2. Dans Variables, prends le bloc rond Score et mets-le à gauche du signe =. Écris 15 à droite.

Ce code va dans le sprite Ball (la balle)

quand @greenFlag est cliqué
attendre jusqu'à ce que <(Score) = (15)>
stop [autres scripts du sprite v] :: control stack
dire [Gagné !] pendant (2) secondes
stop [tout v]

Les 5 blocs forment un seul script, accrochés les uns sous les autres. Pour le premier stop : prends stop tout dans Contrôle, clique sur sa petite flèche et choisis autres scripts du sprite. Tu peux alors accrocher des blocs en dessous.

💡 Ce script attend jusqu'à ce que le score soit égal à 15. Alors stop autres scripts du sprite immobilise la balle, elle dit « Gagné ! », et le jeu s'arrête.

Teste : joue une vraie partie. Arrives-tu à 15 points ?

dans le si … alors de la balle

Ce code va dans le sprite Ball (la balle)

si <touche le [Paddle v] ?> alors
ajouter (1) à [Score v]
ajouter (25) à l'effet [couleur v]
jouer le son [Pop v]
tourner @turnRight de (nombre aléatoire entre (170) et (190)) degrés
avancer de (15) pas
attendre (0.5) secondes
fin

Ajoute les blocs violet et rose. Pour le son : choisis celui que tu veux dans le petit menu du bloc rose, ou ajoutes-en un dans l'onglet Sons.

⭐⭐⭐ La balle annonce ton score quand tu perds

remplace le script « Perdu » de la balle

Ce code va dans le sprite Ball (la balle)

quand @greenFlag est cliqué
attendre jusqu'à ce que <touche le [Line v] ?>
stop [autres scripts du sprite v] :: control stack
dire (regrouper [Perdu ! Ton score : ] et (Score)) pendant (2) secondes
stop [tout v]

Le bloc vert regrouper (dans Opérateurs) colle un texte et un nombre ensemble. stop autres scripts du sprite immobilise la balle pendant qu'elle parle.
